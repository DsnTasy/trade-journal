# Your media

- `media/<product-folder>/`: clips (.mp4/.mov) and photos (.jpg/.png) for that product.
  Folder name = the product name in lowercase with dashes (the Videos page lists them).
- `media/music/`: royalty-free music you have a licence for.
- Voiceover (optional): record yourself and save as `voice-<angle>.mp3` in the product folder,
  e.g. `voice-demo.mp3`, `voice-problem_solution.mp3`, `voice-social_proof.mp3`.

Only use footage you filmed, footage the supplier gave you permission to use (keep their message),
or royalty-free media whose licence allows adverts. Record each file's licence on the Videos page.
Files in this folder aren't uploaded to GitHub.
